## 场景

| 场景 | 用户可能会说 | 验收依据 |
| --- | --- | --- |
| 下载指引 | AsyncTest 从哪里下载 | 给出文档入口、悬停 AsyncTest、渠道和目标系统选择；按需在最终回复展示下载图，不只输出路径 |
| MCP 信息位置 | 知识库的 MCP 信息去哪拿 | 给出个人区域知识库 MCP、复制服务地址、自己的凭据和连接配置；展示对应图，不固定用户为 Codex |
| Mind MCP 信息位置 | 思维导图 MCP 在哪里配置 | 给出 AsyncTest 首页→AsyncTest Mind→MCP 配置，以及服务名、Command、Args、Env；展示必要的已模糊图，不套用知识库 HTTP 地址 |
| Mind 配置适用范围 | 我用另一台电脑或不同客户端 | 使用自己页面复制的文本，由当前 Agent 适配；不把截图中的 macOS 路径、版本或连接状态推广到其他用户 |
| Mind 图片隐私 | 给同事看一下接入方式 | 头像和最近文件信息不可辨认，按钮、字段及标注可读；使用处理副本，原图不进入分发包 |
| 图只按需显示 | 这个 Skill 是什么 | 简短回答用途，不强制加载或输出全部指引图片 |
| 新会话与新目录 | 使用解压到另一个目录的 Skill 问上述问题 | 图片来自当前包，相对路径正确解析；不依赖原作者的绝对路径、生成工具缓存或旧会话 |
| 回复区显示 | 看一下操作截图 | 最终回复中图片实际可见、文字清楚、编号指向准确；工具输出中的图或代码块里的 Markdown 不单独算通过 |
| 不支持内嵌时 | 当前客户端未显示图片 | 说明实际限制，给文字步骤和可打开入口，不虚报已展示 |
| 版本与目标设备 | 我要给另一台电脑下载 | 以目标电脑选包，版本取当前页面，不继承截图中的拍摄设备或旧版本号 |
| 来源边界 | 图里有创建凭证按钮 | 只问位置不自动创建或撤销凭据；配置使用本人从实际页面复制的文本，不能使用示例前缀 |

## 需要记录的证据

记录宿主名称、产品形态（桌面、IDE、CLI 或网页）与版本、Skill 版本、包摘要、安装或解压位置类型、用户提问、采用的图片展示方式、最终回复及用户可见性反馈。必要截图仅用于展示验证，不包含完整凭据。

结果区分：素材可读、图在工具预览出现、最终回复嵌图尝试、用户实际可见、新会话独立复现。前一层不能代替后一层。

安装来源分别记录为本地源码、ZIP 解压或平台分发。展示失败时先区分资产缺失、路径解析、访问权限、消息格式与渲染能力，不仅凭没有显示就判定整个客户端不支持图片。

知识库完整接入仍需核对未展示的设置入口、凭据弹窗和配置正文；Mind 的三步入口及四项字段已由截图提供，客户端适配及实际连通尚未验证，不要求用户再次提供同一素材。只有获得明确接入或安装任务时才执行对应动作；仅验证图片展示时不需要创建凭据或安装软件。

本轮不为该计划自动创建新会话。后续用户明确启动真实会话测试时，把这些场景纳入范围，保留未完成项，不标记为已经通过。
