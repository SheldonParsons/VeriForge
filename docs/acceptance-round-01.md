# 第一轮真实 Agent 验收

测试日期：2026-11-03；报告整理：2026-11-04。

首轮使用 0.4.0-rc.1，通过 4 个独立会话模拟普通用户提问，并实际使用本地工具、知识查询、无界面浏览器和 Mind。发现的问题在 0.4.0-rc.2 中增加约束和交付核对，再进行定向复测。本轮不是所有宿主或所有业务场景的完整验收。

## 怎么测

| 会话 | 实际工作 | 结果与边界 |
| --- | --- | --- |
| A：首次使用 | 项目级安装、用途问答、页面未就绪时怎么开始、自定义表格、知识沉淀时机 | 安装文件与固定提交一致；CLI 和宿主发现接口通过。解释性问答未创建业务记录；未验证界面选择器和全新机器 |
| B：需求与用例 | 主动查询已授权历史与接口知识，切换独立演示项目，澄清含糊需求，按用户四列表格写用例并暂停交接 | 使用实际 KB/NexoFolio 只读工具；区分来源缺失与当前事实。用例从 5 条修订至 7 条，保留旧稿、稳定编号和未确定规则 |
| C：执行与交付 | 演示站前 3 条 UI 场景、跨角色操作、导图与缺陷记录；修复版的收尾复测 | 实际 headless 浏览器操作、Mind 保存和标记回读。首次交付暴露正式记录、编号及 BUG 稿问题；修复版定向核对通过 |
| D：项目隔离与接手 | 登记另一个同号需求，续测剩余场景，随后复验两项缺陷 | 两个项目的相同需求号隔离；没有重跑前 3 条。缺账号和未确认规则保留，缺陷复验与原失败分开记录 |

输入采用普通用户的表达，例如“这个到底能帮我干啥”“这个先放着，我换个小项目”“页面还没出来，先帮我看看怎么测”“前面测过的别重跑”。被测会话没有得到预设缺陷清单。审查侧固定业务事实、演示数据和预设问题，依据原始回执与产物判断结果。

新会话未携带这段开发对话，但仍共享现有宿主、可用工具和本机环境。因此它不能代表一台没有任何既有配置的新电脑，也不能替代真实同事的使用反馈。

## 演示业务结果

演示应用的 7 条原始用例结果为 **1 通过、4 失败、2 阻塞**，4 个失败关联 **2 个预设缺陷**：历史内容被覆盖、保存草稿提示成功但修改未持久化。

切换演示修复版本后，在新申请上验证了两个缺陷现象，均未再出现；原始失败仍保留。缺第二申请人的权限场景、未确认的草稿可见规则、原始提交时间独立比对和旧数据修复没有被改成通过。用例结果、缺陷复验结果和 VeriForge 自身验收结论分别统计。

## 发现的问题与处理

| 编号 | 发现 | 处理与验证 |
| --- | --- | --- |
| VF-001 | 实际执行结果只写入普通日志，正式状态和交接入口仍显示未执行；受管备份可能漏掉相关资料 | 增加执行落盘规程和只读 `delivery.audit`。独立会话补齐 7 条正式结果、证据、导图回执与当前交接；审查侧再次核对通过 |
| VF-002 | BUG 稿未遵循默认段落结构，图片仅以裸路径列在文末 | 加强模板约束与结果区图片检查。修复后正文按步骤、结果、期望组织，真实标注图内嵌于结果中并登记快照 |
| VF-003 | 增补用例后，把显示顺序当作稳定编号，导致执行结果可能关联错误场景 | 固定原始身份依据，结果保存场景标题，交付核对比较 ID 与标题。修复后按原始映射重新登记，保留旧记录及纠正依据 |
| VF-004 | 页面步骤只替换术语，仍有笼统业务动作 | 用户式反馈后，前 3 条补齐实际入口、按钮和角色切换；未观察的操作继续待核对。未宣称整套用例已完成页面验证 |
| VF-005 | 执行者自写了 Python 协调脚本，隐含额外运行环境 | 当前辅助脚本已改为 JavaScript，做了语法、只读计划和防重放检查；Skill 增补新协调脚本使用 Node 的要求。新指引仍需后续独立会话继续验证 |

前三项通过修复版的定向 Agent 收尾复测；后两项经过用户式反馈和产物审查。没有把补救后的结果倒写成首轮一次通过。

另观察到多个 MCP 服务进程共用 Chrome 用户目录时的启动冲突。执行者使用独立 headless 实例完成后续操作，没有终止不明进程。指引已补充 profile 隔离与启动参数核对；这不等于所有宿主已自动配置。

## 本地验证

- 52 项自动检查通过，其中新增 6 项交付核对测试。
- 独立解包、依赖安装及 20 次 CLI 走读通过。
- 审查侧对真实验收工作空间回读：7 条正式结果、载体同步及本地 BUG 关系通过核对。
- 本地备份验证覆盖 451 个受管文件，无登记快照排除项。该结论仅针对受管资料，不包含凭据库、全部临时文件、异地备份或跨机器路径恢复。
- 对本轮提供的演示口令做精确扫描，未在业务工作空间发现持久化明文；这不是完整的秘密检测或安全审计。
